# FileCrypt

파일 → 텍스트 → 파일. 복사·붙여넣기로 파일을 옮기는 도구.
PowerShell 5.1 내장 기능만 사용하므로 오프라인에서 설치 없이 그대로 돌아갑니다.

## 쓰는 법

**보낼 때** — `암호화.cmd` 더블클릭

```
파일 경로 입력  →  텍스트 파일 생성 + 클립보드 자동 복사
```

**받을 때** — `복호화.cmd` 더블클릭

```
클립보드에 붙어있는 텍스트를 알아서 찾아서  →  원래 파일명 그대로 복원
```

끝입니다. 파일을 `.cmd` 아이콘 위로 **드래그해도** 됩니다.

- **암호는 없습니다.** 암호화는 파일 경로 하나만 묻고, 복호화는 아무것도 묻지 않습니다.
- 복원 위치: 클립보드에서 읽었으면 **바탕화면**, 텍스트 파일에서 읽었으면 **그 파일 옆**.
- 같은 이름이 이미 있으면 덮어쓰지 않고 `이름 (1).xml` 로 저장합니다.

## 실제 예시

```
SampleChartControl.cs     54,517 자 / 1,433줄
   ↓ 암호화.cmd
SampleChartControl.cs.enc.txt                 16,408 자 /   163줄   ← 클립보드에 자동 복사
   ↓ 복호화.cmd
SampleChartControl.cs     54,517 자 / 1,433줄   ← 원본과 비트 단위 동일
```

붙여넣을 **글자수가 3.32배 줄었습니다.** XML·CSV·로그처럼 반복이 많으면 10~50배까지 줄어듭니다.

### 글자수가 어디서 줄고 어디서 늘어나는지

```
원본 58,455 B
  → Deflate 압축      11,893 B  (20.3%)   ← 압축은 여기서 끝
  → +암호화 헤더/패딩  12,016 B
  → Base64 (x1.334)   16,024 자           ← 텍스트로 만드느라 33% 되돌아옴
  → +BEGIN/END 줄     16,408 자
```

압축 자체는 -80% 까지 가는데 Base64 가 33% 를 되돌려서 최종 -70% 가 됩니다.
Ascii85 로 바꾸면 15,020 자(-6.3%)가 되지만 그 이상은 어렵습니다.

## 왜 줄어드나

암호화는 크기를 줄이지 않습니다. 압축이 줄입니다. 이 도구는 **압축 → 암호화** 순서로 처리합니다.
(반대로 하면 암호문은 엔트로피가 최대라 압축이 0%입니다.)

```
원본 + 원본 파일명
  → Deflate 압축            (무손실)
  → AES-256-CBC 암호화
  → HMAC-SHA256 인증
  → Base64 텍스트
```

- **원본 파일명이 컨테이너 안에 암호화되어 들어갑니다.** 그래서 텍스트만 붙여넣어도 원래 이름으로 복원됩니다.
- 원본 SHA-256 을 기록해두고 복호화 후 자동 대조합니다.
- 1비트라도 손상되면 **깨진 파일을 뱉지 않고 복호화 자체를 거부**합니다. 붙여넣다 잘린 경우가 조용히 넘어가지 않습니다.

## 보안 수준 — 반드시 알고 쓰세요

`암호화.cmd` / `복호화.cmd` 는 **고정키**를 씁니다. 암호를 묻지 않는 대신, **이 도구를 가진 사람은 누구나 열 수 있습니다.**

- 되는 것: 눈으로 못 읽게 만들기, 전송 중 훼손·변조 감지, 글자수 줄이기
- 안 되는 것: 내용 보호

정말 보호가 필요한 자료는 엔진을 직접 호출해 암호를 거세요 (아래 참고). 암호를 걸면 AES-256 + PBKDF2-SHA256 20만회로 암호를 모르면 열 수 없습니다.

```powershell
.\engine\filecrypt.ps1 -Mode Encrypt -Path 중요자료.xlsx -Armor -Width 100
```

암호를 건 파일을 `복호화.cmd` 에 넣으면 묻지 않고 그냥 거부합니다. 엔진으로 푸세요.

## 붙여넣기 내성

메일·채팅으로 텍스트가 오가면서 생기는 변형을 견딥니다. 아래는 전부 **정상 복원**됩니다.

| 상황 | 결과 |
|---|---|
| 빈 줄이 중간중간 섞임 | 복원 |
| 줄 앞뒤에 공백/탭이 붙음 | 복원 |
| 제로폭 문자(U+200B)가 끼어듦 | 복원 |
| 줄바꿈이 전부 사라져 한 줄이 됨 | 복원 |
| 다른 줄폭으로 다시 접힘 | 복원 |
| 블록 앞뒤에 인사말·본문이 붙음 | 복원 |
| 메일 인용부호 `> ` 가 줄마다 붙음 | 복원 |
| `-----END-----` 줄이 없음 (데이터는 온전) | 복원 |
| **뒤쪽이 잘림 / 중간 줄 누락 / 1글자 변조** | **거부** |

Base64 알파벳이 아닌 문자는 버리고 읽되, 데이터가 실제로 상하면 HMAC 이 잡아냅니다.
**깨진 파일을 조용히 뱉는 경우는 없습니다.** 복원되거나, 거부되거나 둘 중 하나입니다.

## 참고 — 엔진 직접 호출

간편 모드로 안 되는 경우에만 씁니다.

```powershell
.\engine\filecrypt.ps1 -Mode Encrypt -Path data.xml            # 바이너리 .enc 출력
.\engine\filecrypt.ps1 -Mode Encrypt -Path data.xml -Armor -Width 140
.\engine\filecrypt.ps1 -Mode Decrypt -Path data.xml.enc -OutDir .\복원
```

| 옵션 | 설명 |
|---|---|
| `-Armor` / `-Width N` | Base64 텍스트 출력 / 줄폭 (`0` = 한 줄) |
| `-Compress Off` | 압축 끄기 |
| `-Out` / `-OutDir` | 출력 파일 / 출력 폴더 (`-Out` 생략 시 컨테이너에 기록된 원본 파일명 사용) |
| `-Password` | 암호 지정 (간편 모드는 고정키라 안 씀) |
| `-Iterations N` | PBKDF2 반복 (기본 200000) |
| `-Force` | 덮어쓰기 허용 |
| `-Quiet` | 결과 경로 한 줄만 출력 (스크립트용) |

종료 코드: `0` 성공 · `1` 오류 · `2` 취소 · `3` 암호 확인 불일치 · `4` **인증 실패(암호 오류/손상)** · `5` 해시 불일치

## 제한

- 파일 전체를 메모리에 올립니다. 수 GB 파일은 분할하세요.
- 클립보드로 옮길 수 있는 크기에는 현실적 한계가 있습니다. 큰 파일은 생성된 `.enc.txt` 를 그대로 전달하세요.
- .NET Framework 4.7.2 미만에서는 PBKDF2 가 SHA-1 로 폴백되며, 그 사실이 헤더에 기록되어 호환 복호화됩니다.
