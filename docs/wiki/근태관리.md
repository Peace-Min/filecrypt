# 근태관리로 올리고 가져오기

[← 위키 처음](Home.md)

사내 근태관리의 **일간보고 칸**을 텍스트 통로로 씁니다. 일간보고는 날짜당 칸이 하나라 **조각 1개 = 날짜 1개**로 들어갑니다.

## 처음 한 번: 계정

상단 **[계정 정보 관리]** → 아이디·비밀번호 → **[저장]** → **[로그인 확인]**.
비밀번호는 이 PC·이 Windows 계정에서만 풀리게(DPAPI) 저장됩니다. 계정 정보를 남에게 넘기지 마세요.
**[저장된 정보 삭제]** 는 저장된 계정과 로그인용 자격증명을 함께 지웁니다.

## 올리기

1. **파일 → 텍스트** 탭에 파일을 넣습니다(폴더 트리로 일부만 골라도 됩니다).
2. **[근태관리로 올리기]** → 시작 날짜와 한 날짜당 글자수(메인 창 [조각내기] 값이 들어옴)를 확인 → **[올리기]**.

- **[하나로 묶기] 설정과 무관하게 항상 하나로 묶어** 올립니다(가져올 때 한 묶음으로 돌아오도록).
- 이미 내용이 있는 날짜는 **덮어쓰기 전에 묻고**, 원래 내용을 `%LOCALAPPDATA%\FileCrypt\backup` 에 백업합니다.
- 올린 뒤 다시 읽어 날짜마다 같은지, 모았을 때 **원본과 바이트 단위로 같은지**까지 확인합니다.
- 중간에 멈추면 **같은 올리기 창에서** 다시 [올리기] 하면 이미 올라간 날짜는 건너뜁니다.
- 끝나면 가져올 때 쓸 **시작 날짜와 일수**를 알려 주고, 가져오기 창에 미리 채워 둡니다.

### 근태와 초과시간

- 사이트에 있던 근태(휴가 등)와 초과시간은 **그대로 둡니다**.
- 근태가 **비어 있는 날**은 사이트가 근태 없이 저장을 받지 않아 **정근**으로 기록됩니다.

### 주 52시간

근로기준법 주 52시간을 넘기는 날에는 넣지 않고 **건너뜁니다**. 날짜마다 그 날 시간(정근·야근·외근·출장·조퇴·지각 8h,
반차 4h, 특근·휴가·병가 0h + 초과시간)과 사이트가 계산해 둔 그 주(월~일) 나머지 합계를 읽어 판단합니다.

| 그 주 | 결과 |
|---|---|
| 빈 주 | 월~토(48h)에 넣고 **일요일은 건너뜀** → 다음 주 월요일부터 |
| 월~금에 야근 +12h (52h) | **토·일 둘 다 건너뜀** |
| 이미 근태가 있는 날 | 시간이 늘지 않으므로 그대로 넣음 |

건너뛴 날과 이유는 기록 창에 남고("2025-03-09(일): 기록하면 주 56시간 — 52시간 초과라 건너뜀"),
가져올 일수에는 건너뛴 날도 포함됩니다(7조각에 2일 건너뛰면 9일).

## 가져오기

1. **텍스트 → 파일** 탭 → **[근태관리에서 가져오기]**.
2. 시작 날짜와 일수(최대 60일, 31일씩 나눠 읽음), 저장 폴더 → **[가져오기]**.

- 모아서 파일로 되돌리고 **복원된 폴더를 탐색기로 엽니다.**
- **[가져온 뒤 그 날짜들의 보고 내용을 사이트에서 지우기]** 를 켜 두면 **복원에 성공한 뒤에만** 그 날짜 내용을 비웁니다(근태·초과시간은 그대로).

## 그 밖에

- 한 번 로그인하면 세션을 다시 써서 날짜마다 로그인하지 않습니다(사이트가 몰린 로그인을 막기 때문).
- 날짜 사이에 0.7초 쉽니다. `%LOCALAPPDATA%\FileCrypt\config.ini` 에 `netcus.paceMs=300` 처럼 바꿀 수 있습니다(0~10000).
- 문제가 생기면 [계정 정보 관리] → **[기록 보기]** 의 `filecrypt-날짜.log` 에 단계별로 남아 있습니다(비밀번호는 가려짐).
