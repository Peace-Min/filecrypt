# FileCrypt 위키

FileCrypt 는 파일·폴더를 **텍스트 한 덩어리**로 바꿔 복사·붙여넣기(메일, 메신저, 사내 근태관리 일간보고)로 옮기고,
받는 쪽에서 원래 파일과 폴더 구조 그대로 되돌리는 Windows 도구입니다.

> **암호화 도구가 아닙니다.** 키가 공개돼 있어 이 도구를 가진 사람은 누구나 엽니다. 하는 일은 압축 · 눈으로 못 읽게 만들기 · 훼손 감지입니다.
> 기밀 자료를 남이 볼 수 있는 곳에 붙여넣지 마세요.

## 빠르게 시작

1. [설치 파일](https://github.com/Peace-Min/filecrypt/releases/latest)을 받아 실행합니다.
2. **파일 → 텍스트** 탭에 파일·폴더를 끌어 놓고 **[텍스트로 만들기]** → 결과가 클립보드에 복사됩니다.
3. 받는 사람은 **텍스트 → 파일** 탭에서 **[클립보드에서 가져오기]** → **[파일로 되돌리기]**.
