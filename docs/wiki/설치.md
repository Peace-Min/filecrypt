# 설치

[← 위키 처음](Home.md)

## 받기

[GitHub 릴리즈](https://github.com/Peace-Min/filecrypt/releases/latest)에서 **`FileCrypt-Setup-<버전>.exe`** 하나만 받아 실행합니다.

## 요구 사항

| 항목 | 내용 |
|---|---|
| OS | Windows 10/11 **64비트** (32비트는 설치가 막힙니다) |
| 권한 | 관리자 권한 필요 없음 — 현재 사용자에게만 설치 |
| .NET | .NET Framework 4.8 (Windows 10/11 에 들어 있음) |
| 근태관리 기능 | Microsoft Edge WebView2 런타임 (대부분 이미 설치돼 있음) |
| 인터넷 | 파일 ↔ 텍스트 변환에는 필요 없음. 근태관리 기능만 사이트 접속 |

## 설치할 때

- 코드 서명이 없어 **"Windows의 PC 보호"** 창이 뜰 수 있습니다 → **[추가 정보] → [실행]**.
- 설치 위치: `%LOCALAPPDATA%\Programs\FileCrypt` · 시작 메뉴와(선택하면) 바탕화면에 바로가기.
- 이미 설치돼 있으면 덮어씁니다. FileCrypt 가 켜져 있으면 닫을지 묻습니다.
- 창 제목에 버전과 빌드가 보입니다(예: `FileCrypt 2.0.1 (e8a4c70)`). 어떤 빌드가 설치됐는지는 이것으로 확인합니다.

## 제거

**설정 > 앱** 에서 FileCrypt 를 제거합니다. 설정·계정은 `%LOCALAPPDATA%\FileCrypt` 에 남아 있으니 필요하면 직접 지웁니다.

## 설치 파일 만들기 (배포하는 사람)

| 하려는 것 | 실행 |
|---|---|
| 지금 소스 그대로 설치 파일만 | `installer\설치패키지만들기.cmd` — 버전·커밋을 건드리지 않고 `installer\Output\` 에 만든 뒤 폴더를 열어 줌 |
| 버전을 올려 배포 | `installer\setup만들기.cmd` (기본 patch, `-Bump minor` 등) — 버전 올리기 → csproj 커밋 → 빌드 → 설치 파일 |

둘 다 Inno Setup 6 과 dotnet SDK 가 필요합니다. 자세한 것은 [개발 가이드](개발-가이드.md#설치-파일과-릴리즈).
