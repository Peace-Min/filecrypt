# 문제 해결

[← 위키 처음](Home.md)

| 증상 | 원인 · 대처 |
|---|---|
| 설치할 때 "Windows의 PC 보호" | 코드 서명이 없어서입니다. **[추가 정보] → [실행]** |
| 설치가 "64비트 Windows 필요" 로 막힘 | 32비트 Windows 는 지원하지 않습니다 |
| 근태관리 창을 열면 바로 꺼짐 / WebView2 오류 | Microsoft Edge WebView2 런타임이 없는 PC 입니다. 설치 후 다시. exe 만 복사해 쓰는 경우라면 설치 파일로 설치하세요(DLL 13개가 함께 필요) |
| 창 제목의 버전이 예상과 다름 | 다른 빌드가 설치돼 있습니다. 제목의 `(커밋)` 으로 확인하고 최신 설치 파일로 다시 설치 |
| "조각이 모자랍니다 (없는 것: 3, 7)" | 그 번호 조각을 더 넣고 다시 [파일로 되돌리기]. 조각은 순서 상관없음 |
| "손상되었거나 이 도구로 만든 것이 아님" | 붙여넣는 도중 본문 글자가 바뀌었습니다. 원래 `.txt` 파일을 직접 받아 보세요 |
| 경로 칸에 넣었는데 "절대 경로가 아님" | `C:\…` 처럼 드라이브부터 쓰세요. `a.txt`, `.\a.txt` 는 받지 않습니다 |
| [텍스트로 만들기] 가 회색 | 목록이 비었거나, 왼쪽 폴더 트리에서 전부 꺼져 있습니다(계획 줄에 안내) |
| 목록에 흐린 "제외" 파일 | 왼쪽 폴더 트리에서 그 폴더 체크가 꺼져 있습니다 |
| 근태관리 "로그인에 실패했습니다" | [계정 정보 관리] 에서 [로그인 확인]. 비밀번호를 바꿨다면 다시 저장 |
| 근태관리 "다른 근태관리 작업이 진행 중" | 앞 작업이 끝날 때까지 기다렸다가 다시 |
| 근태관리 "응답이 없었습니다" | 사이트가 느리거나 막혔습니다. 잠시 뒤 다시. 같은 창에서 다시 [올리기] 하면 올라간 날짜는 건너뜀 |
| 올린 뒤 "올라간 내용이 원본과 다릅니다" | 사이트가 글을 잘랐을 수 있습니다. 한 날짜당 글자수를 줄여 다시 올리세요 |
| 설치 파일 만들 때 git 오류 | `installer\설치패키지만들기.cmd` 는 git 이 실패해도 커밋 표시 없이 만듭니다 |

더 자세히 보려면 [계정 정보 관리] → [기록 보기] 의 로그(`%LOCALAPPDATA%\FileCrypt\logs`)를 확인합니다.
