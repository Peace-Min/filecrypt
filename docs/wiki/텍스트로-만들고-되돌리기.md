# 텍스트로 만들고 되돌리기

[← 위키 처음](Home.md)

## 파일 → 텍스트

1. 위 토글에서 **파일 → 텍스트**.
2. 파일·폴더를 넣습니다([파일 넣기와 고르기](파일-넣기와-고르기.md)).
3. 옵션을 고르고 **[텍스트로 만들기]**.

| 옵션 | 뜻 |
|---|---|
| **하나로 묶기** | 켜면 전부를 한 번에 압축한 블록 1개(아카이브) — 훨씬 작음. 끄면 파일마다 독립 블록(뒤가 잘려도 앞은 살아남음). 폴더를 넣으면 자동으로 켜짐 |
| **결과를 클립보드에 복사** | 끝나면 결과(조각이면 1번 조각)를 클립보드로 |
| **조각내기** | 결과가 길면 나눕니다. 기본 "20만 자 넘으면 나눔" — 20만 자 이하면 그대로, 넘으면 20만 자씩. 5만/10만/50만, "안 함" |

결과는 **저장 폴더**에 `.txt` 로 생기고 그 파일이 탐색기에서 선택된 채로 열립니다.
실행 버튼 위 계획 줄에 무엇을 할지(파일 수, 방식, 조각 기준)가 미리 보입니다.

조각은 `-----BEGIN FCRYPT PART 3/8 a1b2c3d4-----` 처럼 번호와 묶음 표시가 붙어 있어, 받는 쪽에서 **순서와 상관없이** 모으면 됩니다.

## 텍스트 → 파일

1. 위 토글에서 **텍스트 → 파일**.
2. 받은 텍스트 파일을 끌어 놓거나, 복사해 둔 텍스트를 **[클립보드에서 가져오기]**(조각이면 조각마다 누르면 "조각 5/8 모았습니다" 처럼 알려 줌).
3. **[파일로 되돌리기]**.

- 파일이 하나면 저장 폴더에, 여러 개면 저장 폴더 안에 `FCRYPT 복원 날짜시간` 폴더를 만들어 그 안에 되돌립니다.
- 끝나면 **복원된 폴더(또는 파일)를 탐색기로 바로 엽니다.**
- 원본과 100% 같은지(SHA-256) 확인한 것만 씁니다. 텍스트가 상했으면 되돌리지 않고 알려 줍니다.
- 조각이 모자라면 없는 번호를 짚어 줍니다("없는 것: 3, 7").

## 어떤 통로를 거쳐도

메일 인용부호(`> `), 줄바꿈이 뭉개짐, 앞뒤 인사말, euc-kr 재인코딩, 제로폭 문자가 섞여도 복원됩니다.
본문 글자 자체가 바뀐 경우만 거부합니다(HMAC 이 잡음). 자세한 표는 저장소 [README](../../README.md#어떤-텍스트-통로를-거쳐도-복원된다).

## 맞지 않는 것

- 큰 이미지·동영상·ZIP·EXE: 압축이 안 돼 원본보다 커집니다(약 136%). 기본 설정이면 알아서 조각납니다.
- 수백 MB 이상: 파일 전체를 메모리에 올립니다.
- 경로가 260자를 넘는 깊은 구조: 저장 폴더를 짧은 곳으로.
